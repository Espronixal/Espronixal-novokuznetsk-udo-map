# 🗺️ Интерактивная веб-карта доступности УДО в г. Новокузнецке

Проект представляет собой **интерактивную веб-карту**, позволяющую визуализировать и анализировать **доступность учреждений дополнительного образования (УДО)** для общеобразовательных школ города Новокузнецка.

---

## 🎯 Цель проекта

Оценка географической доступности УДО для школьников с учётом расстояния до ближайшего учреждения.  
Школы, до которых можно добраться до УДО **в пределах 3 км**, считаются **доступными**.

---

## 📊 Источники данных

- `novokuznetsk_schools_accessibility.csv` — содержит:
  - Название школы
  - Координаты (широта, долгота)
  - Ближайшее УДО
  - Расстояние до него (в км)
  - Флаг доступности (`true` / `false`)
- `УДО.csv` — оказался пуст, поэтому координаты УДО **сгенерированы программно** на основе данных о школах.

> 💡 **Важно**: координаты УДО в текущей версии **условные** и используются только для демонстрации связей. Для продакшена требуется загрузка реальных координат УДО.

## 🛠️ Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES5)
- **Карта**: [Leaflet.js](https://leafletjs.com/) + [OpenStreetMap](https://www.openstreetmap.org/)
- **Обработка данных**: Python (библиотеки `pandas`, `geopy` — использовались на этапе подготовки данных)
- **Развёртывание**: GitHub Pages (статический сайт)

---

## 🌐 Функционал

- 📍 Отображение всех школ и УДО на карте
- 🎨 Цветовая маркировка школ:
  - ✅ **Зелёная** — доступно (≤3 км)
  - ❌ **Красная** — недоступно (>3 км)
- 🏷️ УДО отмечены **розовыми метками** с надписью «ДО»
- 🔍 Попап при клике — полная информация о школе/УДО
- 📋 Выпадающий список в правом верхнем углу для выбора конкретной школы
- 🧭 При выборе школы карта центрируется на ней и показывает только УДО в радиусе 3 км
